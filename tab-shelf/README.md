# Tab Shelf — вкладки за категоріями

Розширення для Chrome, яке замінює переповнену панель закладок: зберігайте скільки завгодно вкладок у **бічній панелі** та групуйте їх за кольоровими категоріями.

## Можливості

- **Бічна панель** відкривається кліком на іконку розширення (можна закріпити в Chrome).
- **Категорії** з назвою та кольором (палітра як у груп вкладок Chrome), згортання/розгортання.
- **Збереження вкладки**: кнопка «Зберегти вкладку» → вибір категорії, або «+» у заголовку категорії.
- **Контекстне меню** (правий клік на сторінці чи посиланні) → «Зберегти в Tab Shelf» → категорія.
- **Гаряча клавіша** `Alt+Shift+S` — зберегти поточну вкладку у «Вхідні».
- **Зберегти всі вкладки вікна** — кожна група вкладок Chrome стає окремою категорією.
- **Відкрити категорію** однією кнопкою — посилання відкриваються як група вкладок з тією ж назвою й кольором.
- **Перетягування**: змінюйте порядок посилань і категорій, переносьте посилання між категоріями, перетягуйте посилання зі сторінок прямо в панель.
- **Пошук** за назвою та адресою (Enter — відкрити перший результат).
- **Імпорт з панелі закладок Chrome**: кожна папка стає категорією (доступ до закладок запитується лише в цей момент).
- **Експорт / імпорт** у JSON-файл для резервної копії чи перенесення на інший комп'ютер.
- Світла й темна тема автоматично.

### Нагадування й керування

- **Нагадати про посилання** (дзвіночок біля посилання): через 1–3 години, сьогодні о 18:00, завтра, у понеділок або в обрану дату. Можна поставити повтор: щодня, по буднях, щотижня.
- Приходить **системне сповіщення** з кнопками «Відкрити» та «Відкласти на 1 год». Кількість прострочених нагадувань видно на іконці розширення.
- Вгорі панелі блок **«Нагадування»**: усе заплановане за часом, прострочене виділене червоним, кнопки «Готово» й «Відкласти».
- **Відкласти вкладку**: вкладка закривається й сама відкривається у вибраний час. Кнопка «Відкласти» в панелі або правий клік на сторінці.
- **Нотатки** й позначка **«Зроблено»** для посилань (через «Редагувати»).
- **Автовідкриття категорії за розкладом**: меню категорії «⋯» → «Розклад автовідкриття». Наприклад, «Робота» відкривається по буднях о 9:00 як група вкладок.

Нагадування спрацьовують, поки Chrome запущений. Якщо браузер був закритий, нагадування прийде одразу після запуску.

### Slack

Меню «⋮» → «Налаштування Slack…». Потрібен [Incoming Webhook](https://api.slack.com/messaging/webhooks): api.slack.com/apps → Create New App → Incoming Webhooks → Add New Webhook → канал → скопіювати адресу `https://hooks.slack.com/…`.

- **Дублювання нагадувань у Slack**, щоб вони приходили й на телефон.
- **Підсумок роботи** за розкладом (наприклад, Пн–Пт о 18:00) або вручну («Надіслати підсумок у Slack зараз»): що зроблено сьогодні, прострочені й найближчі нагадування, що збережено за день і, якщо ввімкнено, які вкладки відкриті зараз (за групами).
- **Надіслати список категорії** в Slack (меню категорії «⋯»).

Усе вимкнено за замовчуванням. Доступ до `hooks.slack.com` розширення запитує лише тоді, коли ви зберігаєте адресу вебхука.

Відкриття посилань: клік — у поточній вкладці (як на панелі закладок), `Ctrl`/середня кнопка — у фоновій вкладці, `Shift` — у новому вікні. У меню «⋮» можна ввімкнути «Відкривати в новій вкладці».

## Встановлення (режим розробника)

1. Завантажте репозиторій (Code → Download ZIP) і розпакуйте.
2. Відкрийте `chrome://extensions`.
3. Увімкніть **Режим розробника** (праворуч угорі).
4. Натисніть **Завантажити розпаковане** і виберіть папку `tab-shelf`.
5. Закріпіть іконку через меню розширень (пазл) — клік на неї відкриває панель.

Потрібен Chrome 116 або новіший.

## Структура

| Файл | Призначення |
| --- | --- |
| `manifest.json` | Маніфест (Manifest V3) |
| `background.js` | Service worker: таймери нагадувань і розкладів, сповіщення, контекстне меню, гаряча клавіша |
| `storage.js` | Спільна модель даних і налаштувань у `chrome.storage.local` |
| `reminders.js` | Обчислення часу нагадувань, повторів і розкладів |
| `tabs.js` | Відкриття посилань і категорій як груп вкладок |
| `slack.js` | Формування повідомлень і надсилання у Slack |
| `sidepanel.html/.css/.js`, `ui.js` | Інтерфейс бічної панелі |
| `icons/` | Іконки розширення |

Дані зберігаються локально в браузері (`chrome.storage.local`). Назовні вони йдуть лише у ваш Slack-вебхук, і лише якщо ви це ввімкнули.
